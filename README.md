# Jonas Atelier

![Jonas Atelier embedded library workshop](assets/atelier-banner.svg)

Hi, I’m Jonas Chan. I build robots in my spare time and write the firmware that connects their sensors, motors and controllers.

- **Try a feedback loop on your computer.** Run a heater simulation and watch the controller bring the temperature to its target. [UPID example](https://github.com/JonasAtelier/upid)
- **Connect an ESP32 to a CAN bus.** Send and receive messages with an ESP32 and an SN65HVD230 transceiver. [ESP32 CAN driver](https://github.com/JonasAtelier/esp-sn65hvd230-can)
- **Find a part for your robot.** Browse drivers for ESP32 and STM32, portable C algorithms, and robot projects in development. [Embedded library catalog](https://github.com/JonasAtelier/jonas-atelier-libraries)
